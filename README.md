# Vahan

This mini project involves the integration of a phone interface to automate automobile functions by harnessing the power of a dedicated smartphone app, users gain ability to remotely manage their vehicle. From giving directions to the vehicle to playing music through interface, this system offers an intuitive centralized control mechanism. The project amalgamates hardware and software components to create an interaction between users mobile and automobile, illustrates the potential of smart technology in automotive applications.
